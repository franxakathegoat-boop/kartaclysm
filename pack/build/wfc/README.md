# Kartaclysm WFC client patch (experimental, not shipped)

Generated by `scripts/wfc_gecko_convert.py` from the stage0 Gecko code that
`kartaclysm-wfc/client/build-client.sh <domain>` builds (WiiLink24/wfc-patcher-wii, GPL-2+/BSD-style).

* `kartaclysm-wfc.gct` - LE-CODE/Dolphin build: `prepare.ps1 -WfcGct pack\build\wfc\kartaclysm-wfc.gct`
* `kartaclysm-wfc-riivo.xml` - same patches as Riivolution `<memory>` lines (Pulsar; see note)

Current domain: **kartaclysm.net (placeholder)**. Rebuild both files when the real domain is known.
The default build still uses Wiimmfi.

Pulsar note: the prebuilt Pulsar `Code.pul` applies its own Wiimmfi patch at load time
(hooks at 0x800EE3A0 / 0x801D4EFC and URL strings), which overrides these patches. Pulsar needs an
engine rebuild with Retro Rewind's `WiiLink.cpp` (GPLv3) instead of `Wiimmfi.cpp`. That needs the
CodeWarrior compiler (mwcceppc), which is not on the build box.
